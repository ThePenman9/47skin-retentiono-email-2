# 47 Skin — Retention email portfolio experience

## Journey
Open URL → simulated inbox → open only the 47 Skin message → read the editorial email → back to inbox. All other messages are intentionally not openable.

## Develop
`npm install`
`npm run dev`

## Deploy to Vercel
Upload the **contents** of this folder to a GitHub repository. Import that repository into Vercel (Framework: Vite; build: `npm run build`; output: `dist`). The project name must be lowercase, e.g. `47skin-retention-email`.

## Important portfolio disclaimer
This is a fictional email and inbox for portfolio purposes, not a real email sent or approved by 47 Skin. The models are AI-generated editorial illustrations, not verified customers. The product image is a reference photograph supplied earlier in the conversation.

## CTA caveat
The only supplied destination is `https://47skin.com/products/anti-blemish-scar-repair-serum`. Accordingly, **Share Your Experience** links there. It does not collect or submit feedback; an actual submission experience would need a separately approved feedback URL.
